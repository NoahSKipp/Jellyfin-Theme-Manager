Theme Manager

Install community CSS themes, link your own stylesheets and replace Jellyfin's logo, icons and splash screen. Everything you enable here is composed into a single stylesheet and published through the server's branding CSS, so every client that loads branding picks it up.

Themes

Pick one theme. Installing downloads a copy into the plugin's data folder, so the server keeps working even if the theme's host goes away.

Add-ons

Optional tweaks stacked on top of the active theme, in the order you enable them. Some belong to a specific theme and will pull it in when installed.

Add a stylesheet

Download stores a copy on the server and rewrites relative image and font URLs so they keep resolving. Link leaves the stylesheet where it is and adds an @import, so viewers fetch it from the original host and always get the newest version.

Branding

Replace Jellyfin's images with your own. The logo is swapped with CSS, so it reaches any client that loads the branding stylesheet; the tab and app icons are static files and are swapped by the plugin as the browser asks for them.
